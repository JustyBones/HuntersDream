# HuntersDream
A free, easy to learn and navigate system to help you store and calculate builds for (at this moment) __MonsterHunterWilds__ without any unnecessary bloat or imagery that can lead you away from the main focus.
- This mainly focuses on building armor sets in a layout that is as user friendly -if not more- as the game itself. This means the stupid "slightly increased" to "greatly increased" stat changes will be translated into numbers and percentages.
- To appeal to having all your information in one place it will also include: Information on monsters that are more in detail than the game and every possible location to find all materials as the Wiki (for a lot of them) misses some sources and the Wiki is such a hassle to fix when nobody cares about one bone. But I care, I care a lot.

This is currently in heavy WIP as I know nothing about coding, any tips regarding code and using GitHub will be greatly appreciated. I'll make a discord if enough people are interested in this. If I get good enough, I will consider the possibility of including layered armor outfit making if it is at all possible.
